# Projeto-de-ETL
Pipeline ETL em Python para extração, limpeza e validação de dados sintéticos de milhares de atendimentos de pacientes, com exportação de um arquivo tratado para análise.

# Ideia-Central
O código lê um arquivo, que está no formato csv, salvando-o como um DataFrame Pandas. Após esse processo, o df passa por diversos métodos, a fim de ser tratado. No fim, o arquivo tratado é salvo.
